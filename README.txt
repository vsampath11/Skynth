SKYNTH — FIVE-PAGE WEBSITE REDESIGN
===================================

Main navigation: HOME / PORTFOLIO / SERVICES / ABOUT / CONTACT
Each navigation label has a small icon above it.

The About page includes both the founder introduction and equipment section.
The Portfolio page contains all five collections: Business, Weddings, Nature, Events and Other.
Each collection has four photo slots and one matching MP4 video.

QUICK START
1. Extract this ZIP.
2. Add your photographs to the images folder using exact filenames from PHOTO-VIDEO-GUIDE-SI.txt.
3. Add your MP4 videos to the media folder using exact filenames from the guide.
4. Open index.html locally to preview (a local development server is recommended).
5. Deploy the folder contents to Vercel. index.html must be at the deployment root. No build command is needed.

VIDEO BEHAVIOUR
- Home hero: autoplay, muted, loop, inline, no controls.
- Portfolio category videos: autoplay when their section is near the viewport, muted, loop, inline, native controls visible.
- No video preview JPGs are required.
- Portfolio videos are loaded near the viewport to avoid loading all five at once.
